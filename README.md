# dose ☕ — قهوتك بنقاط

موقع مقهى (باريستا) يعرض المشروبات الساخنة والباردة والحلويات، مع:

- **إعلان بملء الشاشة** تديره لوحة المدير (صورة + عرض/خصم + كل المعلومات في صورة واحدة).
- **نظام طلبات بالنقاط**: الزبون يدخل اسمه، يختار مشروباً، ويرسل الطلب.
- **إشعارات فورية (Web Push)**: عند إرسال الطلب يصل إشعار لجهاز صاحب المحل يعرض اسم الزبون والمنتج والنقاط المكتسبة والرصيد الجديد.
- **لوحة مدير** على المسار `/admin`: إدارة الأصناف، الإعلانات، الطلبات، الزبائن، وتفعيل الإشعارات.

## البنية التقنية

- واجهة: React + Vite (عربية RTL، متوافقة مع الجوال، PWA قابل للتثبيت).
- خادم: Serverless Functions على Vercel (`/api/*`) تتصل بـ Supabase Postgres عبر REST (service role).
- قاعدة بيانات: Supabase (جداول: `products`, `ads`, `customers`, `orders`, `push_subscriptions`, `app_settings` — RLS مفعّل).
- إشعارات: Web Push بمفاتيح VAPID (بدون أي طرف ثالث).

## متغيرات البيئة (Vercel)

| المتغير | الوصف |
| --- | --- |
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_SERVICE_KEY` | مفتاح service_role (سري — للخادم فقط) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة المدير |
| `VAPID_PUBLIC_KEY` | المفتاح العام للإشعارات |
| `VAPID_PRIVATE_KEY` | المفتاح الخاص للإشعارات |
| `VAPID_SUBJECT` | بريد التواصل مثل `mailto:you@example.com` |

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الاستخدام

1. المدير: افتح `/admin` → أدخل كلمة المرور → أضف الأصناف والإعلانات.
2. المدير على هاتفه: تبويب **الإشعارات** → "تفعيل الإشعارات على هذا الجهاز".
3. الزبون: الصفحة الرئيسية → يدخل اسمه → يختار مشروباً → يرسل الطلب → تظهر نقاطه فوراً ويصل إشعار للمحل.
